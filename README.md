# Road Safety Analysis Report, Visakhapatnam

**Version 3.0** | Released 4 October 2026 | Data: January to September 2026

Interactive dashboard for the District Road Safety Committee, Visakhapatnam. January to September 2026.

## What is in this folder

| File | Purpose |
|---|---|
| `index.html` | The complete dashboard and briefing slides in one file. No other files are needed to run it. |
| `robots.txt` | Asks search engines not to index the site. |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are. |
| `README.md` | This guide. |

## Publish with GitHub Pages

1. Create a repository on github.com, for example `vizag-road-safety`.
2. Click **Add file → Upload files** (or the **uploading an existing file** link on a new repository).
3. Drag in **all four files** from this folder. If `.nojekyll` is hidden on your computer, it is optional; the site works without it.
4. Click **Commit changes**.
5. Go to **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
6. After one to two minutes, the site is live at `https://<your-username>.github.io/vizag-road-safety/`.

## Update it later

Upload a new `index.html` over the old one. The site refreshes within a couple of minutes.

## On iPad

Open the link in Safari. Share → **Add to Home Screen** gives a one-tap icon.

## Important

- A GitHub Pages site is **public on the internet**, even if the repository is private, unless your organisation uses GitHub Enterprise private Pages. `robots.txt` and the page's noindex tag keep it out of search engines, but anyone with the link can open it.
- The report contains no personal details from FIRs, but it is official district data. Confirm with the Collector's office that a public link is acceptable before publishing.
